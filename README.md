# 简明 LaTeX 教程

一份面向中文用户的 LaTeX 入门教程源码，围绕「能直接抄用的最小示例」组织，共 64 个主题。

## 覆盖内容

| 分类 | 主题 |
| --- | --- |
| 文档骨架 | 源代码结构、标题作者日期、章节标题与目录、文档结构（前言/正文/附录）、文档拆分 |
| 基础排版 | 换行分段空格、居中与缩进、行距、字号与字体、下划线与颜色、纸张与边距、分页与分栏 |
| 常用环境 | 摘要/摘录/脚注/边注、盒子、自定义命令、有序/无序/描述列表 |
| 图片 | 插入图片、浮动体与图片排版、图片引用、页面背景图、cutwin 文字环绕 |
| 表格 | tabular、浮动环境与引用、三线表、tabularx、tabularray、长表格 longtblr、横向宽表，以及行列样式、边框绘制、单元格合并等 12 组进阶用法 |
| 数学公式 | 数字模式与引用、分式根式、上下标、上下线、求和与样式调整、积分、矩阵、多行公式、分支公式、定理环境与 cleveref |
| 页面与结构 | 页眉页脚、参考文献、索引、目录样式 |
| 绘图 | TikZ：直线坐标、基本图形、线条样式、scope 与样式复用、形变、绘制与填充、文字节点、循环与坐标轴、函数图像 |
| 幻灯片 | beamer 入门 |
| 中文排版 | ctex 补充内容 |

## 编译

需要 **XeLaTeX**（文档使用 `ctexart` 中文文档类）：

```bash
xelatex 简明LaTeX教程.tex
xelatex 简明LaTeX教程.tex   # 跑两遍，目录条目与页码才正确
```

或者用 `latexmk` 一次跑够遍数：

```bash
latexmk -xelatex 简明LaTeX教程.tex
```

环境要求：TeX Live 或 MiKTeX，并安装 `ctex`、`tabularray`、`tikz`/`pgf`、`beamer`、`cleveref` 等宏包。

## 仓库说明
